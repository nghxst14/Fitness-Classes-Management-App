# Identidade da marca — RESTART NOW

Material de marca do cliente, para aplicar na plataforma (Bloco 4 — visual).

## Paleta de cores

| Uso sugerido | Cor | Hex |
|---|---|---|
| Preto principal (fundos, cabeçalho) | ⬛ | `#0F0F0F` |
| Cinza escuro (secções, cartões escuros) | ◼ | `#202020` |
| Verde vivo (destaque, botões, links) | 🟢 | `#5DD62C` |
| Verde escuro (hover, detalhes) | 🟩 | `#337418` |
| Branco / off-white (texto sobre escuro, fundos claros) | ⬜ | `#F8F8F8` |

## Observações

- A marca é escura (dark theme) com o verde vivo como cor de destaque — encaixa
  bem no visual verde que já usámos como base.
- Fonte do logótipo parece uma sans-serif condensada/bold; para o site usamos
  uma sans-serif limpa equivalente.
