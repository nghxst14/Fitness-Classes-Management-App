Esta página explica que dados guardamos sobre ti, para que servem e o que podes fazer em relação a eles.

Quem é responsável

{% if responsavel %}{{ responsavel }}{% else %} [por preencher: nome ou entidade do Sérgio] {% endif %}, que gere a RESTART NOW e é quem decide o que é feito com estes dados.

Que dados guardamos

  • Nome e apelido — para o treinador saber quem está inscrito em cada aula.
  • Número de telemóvel — é o teu identificador de entrada na app e a forma de o treinador falar contigo.
  • Data de nascimento — para o treinador saber os aniversários dos alunos.
  • As tuas marcações — que aulas reservaste, cancelaste ou a que foste.
  • Os teus créditos — o saldo e o registo de cada vez que ele muda (quando compras, reservas ou cancelas).

Não pedimos email, não guardamos dados de pagamento (os pagamentos são tratados fora da app, diretamente com o treinador) e não há publicidade nem partilha dos teus dados com outras empresas.

Porque é que os guardamos

Para te dar o serviço que pediste: marcar aulas, saber quantas sessões tens e manter o registo do que foi comprado e usado. O registo dos créditos existe também para te proteger — é o que permite mostrar, a qualquer momento, porque é que o teu saldo é o que é.

Durante quanto tempo

Enquanto fores aluno, e depois disso durante {% if prazo_anos %}{{ prazo_anos }} ano{{ prazo_anos|pluralize }}{% else %} [por preencher: quantos anos] {% endif %}. Passado esse tempo, os dados são apagados.

Os teus direitos

Podes, a qualquer momento:

  • pedir para ver os dados que temos sobre ti;
  • pedir para corrigir o que estiver errado;
  • pedir para apagar a tua conta e os teus dados.

Para qualquer um destes pedidos, fala com {% if contacto %}{{ contacto }}{% else %} [por preencher: email ou telemóvel de contacto] {% endif %}.

Se apagares a conta, perdes o registo dos créditos que ainda tenhas por usar — por isso vale a pena falar com o treinador antes.

Quem tem acesso

Só o treinador e quem ele autorizar a gerir a aplicação. Os teus dados ficam guardados no servidor onde a aplicação corre e não são vendidos nem cedidos a ninguém.

Se não concordares com alguma coisa

Fala primeiro connosco. Se ainda assim entenderes que os teus dados não estão a ser bem tratados, podes apresentar queixa à Comissão Nacional de Proteção de Dados (CNPD), a autoridade portuguesa para estes assuntos.
